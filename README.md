# Vocoby

Англо-русский словарь-тренажёр для GitHub Pages. Статический сайт без сервера, сборщика и npm-зависимостей.

## Как играть

На экране пять английских слов и перемешанные переводы. Нажмите слово и перевод в любом порядке. Совпавшая пара заменяется следующей; остальные карточки остаются на месте. Ошибка позволяет попробовать снова. В конце подборки можно начать повторение.

Подборки фильтруются по уровню и первой букве. По умолчанию открывается практическая база A1 из 400 частотных слов; полный словарь можно выбрать вручную. Пройденные слова сохраняются в localStorage этого браузера; синхронизации между устройствами нет. Повторение сбрасывает только выбранную подборку. Прохождение пары — отметка о выполнении, а не оценка владения словом.

На главной странице показываются общее число изученных слов и серия дней занятий. После первого открытия приложение кэширует оболочку и уже загруженные порции, поэтому ранее открытые слова доступны без сети; для первой загрузки и новых порций интернет всё ещё нужен.

## Локальный запуск

Нужен Python 3:

```sh
python3 -m http.server 8000
```

Откройте http://localhost:8000. Открытие index.html двойным кликом не подходит: словарь загружается через fetch.

## Публикация

1. Отправьте файлы в ветку `main` своего GitHub-репозитория.
2. В **Settings → Pages → Build and deployment → Source** выберите **GitHub Actions**.
3. Запустите workflow **Publish GitHub Pages** во вкладке Actions или отправьте новый коммит в main.

Workflow проверит код, соберёт словарь, опубликует статический сайт вместе с Service Worker и покажет адрес deployment, обычно `https://jollu8.github.io/vocoby/`. Относительные пути работают и в подпапке репозитория.

[Документация GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).

## Словарь WikDict

В проект включено **33 551 реальных уникальных английских написаний с русскими переводами**. Четыре низкоценные записи (`a`, `ab`, `aah`, `aardvark`) исключены. Практические базы содержат по 400 частотных слов A1, A2, B1 и B2 с отсеянными явно плохими переводами; это частотные подборки, а не сертифицированная CEFR- или Oxford-разметка. Остальные импортированные карточки находятся в категории **«Без уровня»**.

Источник: [WikDict, англо-русский снимок 2026-06](https://download.wikdict.com/dictionaries/sqlite/2_2026-06/en-ru.sqlite3), на основе Wiktionary через DBnary. Адаптированные данные — **CC BY-SA 4.0**, отдельно от лицензии кода. Атрибуция, условия и изменения — в [data/LICENSE.md](data/LICENSE.md) и на странице [sources.html](sources.html). Отчёт с контрольными суммами — [data/import-report.json](data/import-report.json).

Импорт использует отметку качества `is_good`, исключает имена собственные, фразы, записи не в нижнем регистре, английские слова длиннее 28 символов и русские варианты длиннее 32 символов / трёх слов. Допускаются дефис и апостроф в английских словах. Знаки ударения убираются, буквы ё и й сохраняются. Для каждого английского написания выбирается одна запись по убыванию `score`, затем `importance`, с фиксированным порядком при равенстве; из неё берётся первый подходящий перевод. В CSV сохраняются исходный идентификатор и описание выбранного значения.

Это автоматический отбор, **не ручная проверка всех переводов**. Выбранное значение может быть редким или специальным (например, `set → сет`), присутствуют термины, разговорная лексика и производные формы. Число записей не означает число независимых лемм или учебных значений. Многозначность и интервальное повторение пока не реализованы.

### Повторить импорт

Python 3, без сторонних библиотек:

```sh
curl -fL https://download.wikdict.com/dictionaries/sqlite/2_2026-06/en-ru.sqlite3 -o /tmp/vocoby-en-ru.sqlite3
python3 scripts/import_wikdict.py /tmp/vocoby-en-ru.sqlite3
python3 scripts/build_dictionary.py
npm test
```

Импорт проверяет SHA-256 закреплённого снимка и воспроизводимо создаёт CSV и отчёт. Исходная SQLite-база (~20 МБ) не входит в сайт и не загружается браузером. Стартовый набор хранится отдельно в `data/starter.csv`. Для другого снимка нужно проверить изменения и обновить URL/контрольную сумму импортёра, отчёт и сведения на странице источников.

Готовые CSV и JSON включены в репозиторий: для локального запуска и публикации повторно скачивать WikDict не требуется. Сборка GitHub Pages работает с готовым CSV. Ссылка на скачивание полного CSV доступна на странице источников; сама игра его не запрашивает.

Источник — `data/words.csv` в UTF-8:

```csv
en,ru,level
apple,яблоко,A1
believe,верить,A2
achieve,достигать,B1
```

Добавьте слова и выполните:

```sh
python3 scripts/build_dictionary.py
```

Сборщик поддерживает уровни A1–C2 и `ungraded` («Без уровня»), проверяет обязательные поля и дубликаты английских слов. Слова сортируются по алфавиту внутри уровня. Каждая пара «уровень + первая буква» разбивается на JSON-файлы максимум по **200 слов**. Стабильный ID зависит от английского слова. Каждая порция имеет версию по хешу содержимого: прогресс неизменённых порций сохраняется, изменённые порции проходят заново. Добавление слов может изменить несколько порций из-за пересортировки.

`data/manifest.json` содержит только метаданные порций: уровень, букву, путь, количество слов и версию содержимого. Идентификаторов всех слов в начальной загрузке больше нет.

Для повторного построения практических баз скачайте частотный список с одним словом в строке и выполните `python3 scripts/promote_frequency.py frequency.txt`, `python3 scripts/curate_a1.py frequency.txt`, `python3 scripts/expand_levels.py frequency.txt`, затем `python3 scripts/build_dictionary.py`. Скрипты сохраняют текущие уровни, очищают A1 и добавляют частотные слова в A2, B1 и B2.

Для очистки самой базы A1 используйте `python3 scripts/curate_a1.py frequency.txt`, затем снова выполните `python3 scripts/build_dictionary.py`. Сомнительные записи переводятся обратно в «Без уровня», а на их место берутся следующие частотные слова.

WikDict не содержит CEFR-уровней, поэтому импортёр не выдумывает их: такие слова получают `ungraded`. Чтобы разнести подтверждённые слова по уровням, подготовьте CSV `levels.csv` с колонками `en,level` и запустите импорт с `--levels levels.csv`. Допустимые значения: A1, A2, B1, B2, C1, C2; неизвестные слова останутся без уровня. Уровни из этого файла применяются до стартового набора, поэтому ориентировочные уровни Vocoby сохраняются.

### Скорость на большой базе

- Первая загрузка: маленький manifest, нужная порция до 200 слов и одна следующая порция в фоне. Полностью пройденные порции пропускаются без скачивания.
- В очереди не больше 200 слов, в предзагрузке — ещё одна порция. Совпадающие переводы временно уменьшают число карточек, вместо скачивания остальных файлов в поиске уникальных ответов.
- Нажатие обрабатывает только 10 существующих кнопок и текущую очередь. Подсчёт прогресса по порциям происходит при выборе подборки, после совпадения счётчик увеличивается на единицу.
- Новая пара берётся из памяти. Если сеть задерживается, доступные карточки остаются активными. Подсветка верного ответа занимает 180 мс, ошибки — 350 мс; это намеренная обратная связь.
- Прогресс хранится отдельно для каждой версии порции (до 200 ID в записи). Запись отложена до свободного времени браузера, а при уходе со страницы выполняется сразу. При аварийном завершении браузера последние несохранённые ответы могут потеряться.
- При смене фильтра запросы предыдущей подборки отменяются. Ошибки фоновой загрузки можно повторить. Версия в URL порции предотвращает использование старого содержимого после обновления.
- Внешние шрифты не загружаются: используется системный шрифт устройства.

Старый формат прогресса переносится при загрузке соответствующих порций; поэтому старые результаты могут проявляться постепенно. На старте читаются локальные записи прогресса по выбранным порциям, а не тексты всего словаря. Это отдельная работа при открытии подборки, не при каждом нажатии.

Автотесты проходят все 30 000 синтетических слов, проверяют границы буфера, количество запросов, пропуск пройденных порций, ошибки предзагрузки, отмену и перенос прогресса. Размер manifest для этой тестовой базы ограничен 40 КБ без сжатия. Это проверки алгоритма, а не замеры скорости реального телефона и мобильной сети.

На включённой базе manifest занимает 38 740 байт без сжатия, самая большая порция — 15 249 байт. Тест дополнительно проходит все 33 555 реальных записей с пятью активными карточками и проверяет отсутствие пропущенных слов, дубликатов ID, неоднозначных видимых пар и неограниченной загрузки. Скорость на конкретном телефоне зависит от устройства и сети.

Разбиение решает вопрос загрузки большого файла, но **не защищает словарь от скачивания**: все данные статического сайта публичны. Лицензия кода в LICENSE не заменяет лицензию импортированного словаря.

## Проверки

Нужны Node.js 18+ и Python 3, установка npm-пакетов не требуется:

```sh
npm test
```

Проверяются перемешивание, отсутствие неоднозначных пар, разбиение данных, стабильность ID и отклонение невалидного CSV.
