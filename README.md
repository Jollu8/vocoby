# Vocoby

Мой личный англо-русский тренажёр слов. Аналогичного формата мне не хватало, поэтому сделал его для себя.

## Пользоваться

Просто откройте сайт и тапайте по словам:

**[Открыть Vocoby](https://jollu8.github.io/vocoby/)**

Выберите английское слово и его перевод. Прогресс сохраняется в браузере, поэтому можно вернуться позже и продолжить.

Есть уровни A1, A2, B1 и B2, подборка по первой букве, статистика и офлайн-доступ к уже загруженным словам.

A1 заменён подборкой [Vocabden](https://vocabden.com/en/english-a1-word-list): 898 уникальных слов и выражений из 1073 записей источника. Повторы разных частей речи объединены, русские переводы проверены и исправлены для начинающих. У нового A1 отдельный прогресс; результаты старой базы 400 в него не переносятся.

A2 заменён вашим списком из `data/a2-user.md`: 877 уникальных слов и выражений из 1000 строк. Переводы сохранены; повторяющиеся слова объединены с сохранением вариантов значения. У новой подборки отдельный прогресс.

B1 заменён вашим списком из `data/b1-user.md`: 394 уникальных слова и выражения из 400 строк. Повторы объединены, переводы сохранены. У новой подборки отдельный прогресс.

B2 заменён вашим списком из `data/b2-user.md`: 394 уникальных слова и выражения из 400 строк, включая фразовые глаголы. Повторы объединены, варианты перевода сохранены. У новой подборки отдельный прогресс.

В меню «Сложность» также есть **most 1000** — все 1000 слов из [The Vocabulary.com Top 1000](https://www.vocabulary.com/lists/52473) с русскими переводами. Это сложные распространённые слова для академических и деловых текстов, а не базовая частотная тысяча. Прогресс этой подборки сохраняется отдельно.

## Источник

Слова взяты из [WikDict](https://www.wikdict.com/) и адаптированы для этого тренажёра. Данные распространяются по [CC BY-SA 4.0](data/LICENSE.md).

Подробности об источниках: [sources.html](sources.html).

Сборка всех подборок: `npm run build:dictionary`. Исходники дополнительных подборок — `data/most-1000.csv`, `data/a1-vocabden.csv`, `data/a2-user.csv`, `data/b1-user.csv` и `data/b2-user.csv`; определения и примеры сайтов не копируются. Приложение заменяет старые A1–B2-чанки базового манифеста чанками `data/a1-vocabden/`, `data/a2-user/`, `data/b1-user/` и `data/b2-user/`, сохраняя остальные уровни и их ключи прогресса. Старые A1–B2-данные остаются только в исходной выгрузке и не используются в тренажёре.
